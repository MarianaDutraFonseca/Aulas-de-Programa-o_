Exercício 1 — Cadastro de Produto Desenvolva um programa em PHP utilizando Programação Orientada a Objetos para representar um produto de uma loja. A classe deverá se chamar Produto e possuir os atributos: nome preço quantidade em estoque Todos os atributos devem ser privados (private). O sistema deve permitir: cadastrar os dados do produto; validar as informações inseridas; exibir os dados cadastrados. Regras importantes: o nome não pode ser vazio; o preço deve ser maior que zero; a quantidade não pode ser negativa. Ao final, exiba todas as informações do produto na tela. 💡 Dicas: Utilize métodos getters e setters. Faça as validações dentro dos setters. Utilize trim() para evitar espaços vazios no nome. Use is_numeric() para validar números. Utilize number_format() para mostrar o preço formatado. Tente impedir que valores inválidos sejam gravados. Crie um método como mostrarProduto() para organizar a saída. Lembre-se: atributos privados só podem ser acessados por métodos da própria classe. _____________________________________________________________________________________ Exercício 2 — Conta Bancária Crie um sistema simples de conta bancária utilizando PHP Orientado a Objetos. A classe deverá se chamar ContaBancaria e possuir: titular saldo Os atributos devem ser privados. Implemente funcionalidades para: depositar dinheiro; sacar dinheiro; consultar saldo. O sistema deve obedecer às seguintes regras: não permitir depósitos negativos; não permitir saque maior que o saldo disponível; o saldo não pode ser alterado diretamente fora da classe. Ao final do programa, realize algumas operações e exiba o saldo atualizado. 💡 Dicas: Utilize métodos públicos para manipular o saldo. O saldo deve iniciar em 0. Crie mensagens informando sucesso ou erro nas operações. Utilize estruturas condicionais (if) para validar operações. Pense como um banco real: nunca permitir saldo negativo. Utilize um método chamado consultarSaldo(). Teste diferentes cenários de saque e depósito. Não permita que o usuário altere o saldo diretamente. _____________________________________________________________________________ Exercício 3 — Cadastro de Aluno Desenvolva uma classe chamada Aluno para armazenar informações de um estudante. A classe deve possuir os atributos privados: nome nota1 nota2 O sistema deve: permitir cadastrar as notas; calcular a média; informar a situação do aluno. Regras: as notas devem estar entre 0 e 10; o nome não pode ser vazio. Situação do aluno: média maior ou igual a 7 → aprovado; média entre 5 e 6,9 → recuperação; média abaixo de 5 → reprovado. Ao final, exiba: nome; notas; média; situação final. 💡 Dicas: Utilize métodos específicos para calcular média. Evite acessar atributos diretamente. Use operadores lógicos para validar as notas. Utilize round() para limitar casas decimais da média. Crie um método chamado verificarSituacao(). Pense na reutilização do código. Faça testes com alunos aprovados, reprovados e em recuperação. Organize a saída utilizando echo e quebras de linha. _____________________________________________________________________________ Exercício 4 — Sistema de Funcionários Crie uma classe chamada Funcionario. A classe deverá possuir os atributos privados: nome cargo salário Implemente um sistema que permita: cadastrar funcionário; aumentar salário; exibir informações atualizadas. Regras: o nome não pode ser vazio; o cargo não pode ser vazio; o salário deve ser maior que zero; o aumento salarial deve utilizar percentual. Ao final, exiba os dados do funcionário antes e depois do aumento. 💡 Dicas: Utilize encapsulamento corretamente. O salário deve ser alterado somente por métodos da classe. Crie um método chamado aumentarSalario($percentual). Utilize cálculo percentual: salário + (salário * percentual / 100) Não permita percentual negativo. Utilize number_format() para exibir salários. Teste aumentos diferentes. Organize a exibição em formato de relatório. ______________________________________________________________________________ Exercício 5 — Sistema de Usuários Desenvolva um sistema de autenticação simples utilizando PHP OO. Crie uma classe chamada Usuario contendo os atributos privados: login senha O sistema deve permitir: cadastrar usuário; alterar senha; autenticar login. Regras: o login deve possuir pelo menos 4 caracteres; a senha deve possuir pelo menos 8 caracteres; a senha não deve ser acessada diretamente fora da classe. Ao final, teste diferentes tentativas de login e exiba mensagens de sucesso ou erro. 💡 Dicas: Utilize getters e setters. Utilize encapsulamento para proteger os dados. Utilize strlen() para validar tamanho do login e senha. Crie um método chamado autenticar(). Utilize estruturas condicionais para comparar login e senha. Teste login correto e incorreto. Organize mensagens claras para o usuário. Pense em como sistemas reais protegem informações privadas. ______________________________________________________________________________
